Every line here is provisional. It is not the chart note. Stopping does not create a draft.

How this page connects

  1. The service must already be running (python main.py in LiveVisitScribe). It listens on port 8037.
  2. Open this page at http://localhost:8037/try. Check health hits GET /api/v1/health.
  3. Start visit asks for the microphone, opens ws://localhost:8037/api/v1/live, and sends the text frame below.
  4. After {"type":"ready"}, each ~100 ms block of mic audio is converted from float samples to little-endian int16 PCM and sent as a binary frame. The service resamples to 16 kHz.
  5. Or use Stream sample visit to play the bundled 3-minute doctor/patient WAV into the same socket (no microphone).
  6. Pause / Resume / Stop are text frames. Stop flushes the open line, sends final, and the server closes the socket.
